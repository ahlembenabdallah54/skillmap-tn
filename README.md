# SKILLMAP TN

Agentic AI platform for job market analysis,
skill gap identification and personalized
career roadmaps in Tunisia.

## Objectives

- Analyze Tunisian job market data
- Extract demanded skills from job offers
- Classify professional profiles
- Identify students' skill gaps
- Generate personalized career roadmaps
- Use Agentic AI to orchestrate the analysis

## Technologies

- Python
- Streamlit
- Pandas & NumPy
- Scikit-learn
- spaCy
- LangGraph
- SQLite
- Plotly
